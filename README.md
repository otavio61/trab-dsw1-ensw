# Projeto AMO (Arcade Machine Object)

## Sobre

O projeto faz parte do desenvolvimento da matéria "Desenvolvimento de sistemas web 2" e tem como objetivo exercitar os conhecimentos sobre o desenvolvimento de sites, tendo foco maior no backend com PHP, como processamento pelo lado do servidor e manipulação de banco de dados SQL

### Ferramentas utilizadas

VS Code, XAMPP, PHP, MySQL (PHPMyAdmin)

## Instalação e execução do projeto

Basta clonar/baixar o respositório e abrí-lo em uma IDE ou editor de texto de sua preferência. Recomenda-se utilizar o VS Code para o projeto, pois o repositório já
possui a configuração necessária para execução. Além disso, é necessário colocar o
repositório na pasta 'htdocs', caso seja utilizado o XAMPP.
